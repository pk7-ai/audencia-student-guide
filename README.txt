# Audencia Student Guide — prototype

## Run locally
Open `index.html` in a modern browser. Keep the `assets` folder next to it.

## Publish for everyone
This folder must be hosted on a public HTTPS website before a QR code can point to it.
A simple option is GitHub Pages:
1. Create a public GitHub repository.
2. Upload `index.html` and the `assets` folder.
3. In Settings → Pages, deploy from the `main` branch / root folder.
4. Copy the public URL (for example, `https://username.github.io/repository/`).
5. Generate a QR code from that exact URL.

## Data integrity
Facility lists are transcribed from the Audencia wayfinding plan images supplied for this project. Individual service room numbers, emails, phone numbers and opening hours were not confirmed by those plans and are intentionally not fabricated.
